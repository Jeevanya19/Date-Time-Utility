# Date and Time Utility

## Description

This is a simple Python program that performs useful date and time calculations using the built-in `datetime` module.

## Objective

To learn practical date and time manipulation in Python.

## Features

- Calculate age from date of birth.
- Calculate the number of days between two dates.
- Calculate working days excluding Saturdays and Sundays.
- Display the current date and time in a formatted format.
- Validate date inputs and handle invalid menu choices.

## Tools Used

- Python
- datetime module

## How to Run

1. Install Python on your computer.
2. Save the program as `date_utility.py`.
3. Open a terminal or Python IDLE.
4. Run the program.
5. Select an operation from the menu.
6. Enter dates in `DD-MM-YYYY` format.
